# Arena records and strategy

In **Arena**, the account record loads from the selected arena's native information RPC while idle. **Refresh totals** reloads it on demand; account totals refresh before queueing and after completed arena battles. Each mode has its own cached record and update time. Account totals are never replaced with this run's wins or incremented locally when a refresh fails. A failed post-battle refresh retains the last verified totals with a stale-data message.

Battle Arena reads `info.stats.ba_wins`, `ba_losses` and `ba_weekly_wins`; Random Arena reads `ra_wins`, `ra_losses` and `ra_monthly_wins`. Platinum reads `pa_wins`/`pa_losses` if supplied in `info.stats` or `info`; its native panel exposes `pa_streak` and `pa_max_streak`, which are shown separately. Missing lifetime values display a dash, never a guessed value based on streak or reward progress. Server records can reflect manual/native play and survive automation restarts. The separate run counters and run win rate start over under the existing run/sign-in rules.

Select **Smart: matchup and survival**, save arena settings, then Start. **Basic: highest attack power** remains available for comparison. These preferences affect arena combat only; hunt/capture behavior remains unchanged.

Smart uses the following bounded rules:

- Score legal attacks by AP, accuracy, hit count, native elemental matchup and the species' relative physical/elemental stat profiles. The native chart is Nature → Water → Fire → Nature and Wind → Earth → Lightning → Wind. Element advantage is 2× and resistance 0.5×; Negate changes the respective advantage/resistance checks. Physical attacks stay neutral to the element chart.
- Prefer a likely finishing attack when the same attack has already dealt sufficient damage against the same opponent in the current battle. Multi-hit observations are summed, and changes to buffs, Negate or switches invalidate those observations. This is a conservative estimate, not a guarantee against hidden effects or random damage.
- Consider self-healing below 60% HP, give it more weight below 30%, cap the value at missing HP, and avoid it during known antiheal. Use Poison/Dot against healthier enemies rather than repeatedly applying an already active effect. Control considers accuracy and known Sleep/Confuse immunity. Negate and Cleanser are considered when relevant weakness or harmful effects are active.
- Consider switching a critically injured teammate only to a substantially healthier, safer matchup. If no useful action is available, a healthy reserve is considered. Respect paralyze, native switch penalties and an anti-loop guard requiring an attack before another voluntary switch. The policy does not assume a speed-control/double-turn opportunity from hidden opponent stats.
- Honor current cooldowns and remaining uses. For arenas, normal attacks that miss do not consume a successful-hit cooldown, once-only moves stay available after a miss, and native Sleep/Confuse special cooldowns use 5 on success / 4 on miss before round recharge. Random Arena applies AP, accuracy, duration and explicit additional enchant effects from official metadata to its generated teams.

Random Arena draft ranking now considers available attacks, accuracy, hit counts, stat profiles, healing, damage-over-time and Negate. Picks also reward additional element coverage. Rarity contributes only a small tie-breaking weight. Choices remain limited to the server's pool, six bans and four unbanned picks. The basic battle setting does not restore the old rarity-only draft ranking.

During battle, Arena displays the latest reason for the automatic choice. The policy neither buys upgrades/potions/relics nor changes the owned collection team. Complex ability combinations and hidden opponent builds are not fully simulated. Species grades are relative heuristics, not claimed live stat values or the server's damage formula. An opponent can make a different decision than the heuristic anticipates.

## Research and validation

The [official game website](https://worldofmiscrits.com/) identifies elemental advantages, abilities and team composition as combat mechanics. Detailed rules were checked against primary native 2.23.0 resources in this package: `models/BattleMiscrit.gd` (`weak_against`, `get_ability_text`, cooldown setup), `models/Ability.gd` (miss/success recharge), `scenes/common_ui/abilities/battle_ability_button.gd` (Negate checks), `scenes/battle/battle_container_v2.gd` (status durations, cleanse/purge lists), `battle_player.gd` (switch penalty), and extracted arena panels (record field names). Current abilities/stat grades are loaded from the [official Miscrits data feed](https://cdn.worldofmiscrits.com/miscrits.json). Community search results were not used as authority for hidden damage or speed-control calculations.

172 automated tests pass, including explicit element direction/Negate cases, physical versus elemental profiles, accuracy/multi-hit choices, legal moves, heal/antiheal/finisher choices, status/control immunity, switch penalties and anti-loop behavior, common status updates, special miss cooldowns, damage observation invalidation, mixed draft coverage, Smart/Basic engine actions, server totals independent of run counts, stale totals, authenticated stats refresh and unknown Platinum values in the UI.

No higher live win rate is claimed: these are tested decision improvements, not an online-trained model or a measured win-rate benchmark. No arena matches were started on the signed-in account during this update. Browser automation was unavailable for visual layout inspection. Use the displayed run win rate to observe real results; opponent strength and small sample sizes affect comparisons.
