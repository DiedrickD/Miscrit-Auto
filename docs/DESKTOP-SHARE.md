# Paket desktop untuk dicoba

Versi 21 Oktober 2026 menggunakan client 2.23.0 dan runtime Godot 4.6, Windows 64-bit.

[Unduh paket portable](https://github.com/azure722/Miscrit-Auto/releases/tag/desktop-2026.10.21), ekstrak semuanya, lalu buka **Launch Auto Capture.cmd**. Gunakan akun sendiri dan jalankan Steam untuk login Steam. Internet diperlukan untuk login dan bermain. Tutup client lain yang memakai akun yang sama.

Paket menyertakan launcher CMD/VBS/PowerShell, executable game, dua DLL dan BACA-DULU.txt. Pengaturan, riwayat, token, diagnostik, backup, hasil tes dan screenshot lokal tidak masuk ZIP. Pengaturan baru akan dibuat di folder hasil ekstraksi.

Versi ini menyediakan pemilihan target, aturan capture, campaign dan latihan koleksi 17+ sampai level 35. Baca [panduan koleksi](DESKTOP-COLLECTION-WORKFLOW.md), [aturan level 35](DESKTOP-LEVEL35-TRAINING.md), dan [diagnostik target](TARGET-CAPTURE-DIAGNOSTICS.md).

Paket installer di repository merupakan alternatif lebih kecil. Jalankan **Auto-Capture-Game-Installer/Install Auto Capture.cmd** dan pilih instalasi Miscrits Steam 2.23.0 yang kompatibel. Setelah instalasi, buka launcher di folder installer. Installer memverifikasi kompatibilitas resource dan checksum payload sebelum membuat salinan game terpisah.

Verifikasi rilis memakai tes desktop offline terisolasi, pemeriksaan checksum payload installer, dan pemeriksaan isi ZIP. Tes ini tidak memverifikasi login atau gameplay online dari komputer teman. SHA256 ZIP tersedia sebagai file pendamping di halaman rilis.
